# Реестр открытой работы

**Это не спецификация.** Шаблону спецификаций не следует и в автоматические
обходы «что можно взять в работу» попадать не должен — исключается по имени
файла (`backlog.md`), а не по расположению.

Здесь то, что известно и не сделано по всему репозиторию. Два источника
пополнения: именованные остатки спецификаций и то, что всплывает при работе.
Строка удаляется, когда работа сделана, а не помечается «готово» — правится по
ратчету, объём не растёт монотонно.

Даты последней сверки здесь нет намеренно: рукописное поле «когда проверяли»
гниёт по построению, а историю правок и так знает git.

Ворота пройдены: 60 пакетов, без pandas/numpy/pyarrow, `duckdb` уже наш | Для производных данных у нас нет ни контрактов, ни тестов — только описание намерения. **Триггер: после спайка первой недели** — сравнивать не на чем, пока нет ни одного документа. Не замена системе истины: сущности и порты в dbt непредставимы |
