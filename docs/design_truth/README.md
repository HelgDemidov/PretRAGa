# Система контроля архитектурной истины (design truth)

Истина архитектуры — само доменное кольцо `src/pretraga/domain/`: рукописной
модели рядом с кодом нет, обязательства пород исполняются при создании
класса, дрейф ловится гейтом на трёх поверхностях (форма схемы, направление
колец, сами данные).

- **[Чартер и руководство](charter/charter.md)** — суть, оси, четыре
  рукописные точки, механизмы, повседневные операции. Читать первым.
- **[Словарь понятий](domain_glossary.md)** — генерируется из кода
  (`tools/truth.py --build`), руками не правится.
- **`tech_specs/`** — индивидуально реализуемые спецификации изменений
  этой системы.

Контракт формы схемы — `schema.lock.json` в корне репозитория, рядом с
`uv.lock`. Гейт — команда в `CLAUDE.md` §10.
