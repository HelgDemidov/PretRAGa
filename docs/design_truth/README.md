# Система контроля архитектурной истины (design truth)

Второе поколение: рукописной модели рядом с кодом нет — истина архитектуры
это само доменное кольцо, ограниченное так, что ложь в нём не создаётся
(обязательства пород исполняются при создании класса), а дрейф не проходит
гейт. Обоснование, оси и верификация — в
[спеке](tech_specs/design-truth-replacement/spec.md); этот файл — вход:
где что живёт и что здесь рукописное.

## Где что живёт

| Артефакт | Писатель | Что это |
|---|---|---|
| `src/pretraga/domain/` | человек | сама модель: понятия, порты, словари, конвенции |
| `[tool.importlinter]` в `pyproject.toml` | человек | правила колец |
| `CASES` в `tests/test_conformance.py` | человек | пары порт↔реализация |
| поле `version` в `schema.lock.json` | человек (через `--write --version`) | признание ломающего изменения |
| `docs/design_truth/domain_glossary.md` | `tools/truth.py --build` | читаемая сводка модели |
| `schema.lock.json` (корень, рядом с `uv.lock`) | `tools/schema_lock.py --write` | контракт формы схемы |

## Четыре рукописные точки и правила работы с ними

Каждый рукописный факт записан ровно один раз, и у каждой точки есть
механизм-вымогатель — сгнить молча не может ни одна.

1. **`src/pretraga/domain/`** — правка домена и есть разработка модели;
   отдельного акта «обновить истину» не существует. Машина сюда не пишет.
   Каждую правку держат: породы (`KindError` при импорте), классификатор
   ролей, лок формы, mypy, хук сессии.
2. **Контракты колец** — меняются только сознательным архитектурным решением,
   никогда «чтобы прошло»: контракт, подстроенный под текущие импорты,
   замораживает статус-кво вместо правила.
3. **Конформанс-реестр** — новая реализация порта = одна запись `Case`;
   забыть нельзя: порт без записи числится поимённо в списке непокрытых,
   который меняется только сознательно.
4. **Версия схемы** — единственное человеческое решение при ломающем
   изменении формы: `tools/schema_lock.py --write --version X.Y.Z`, и там,
   где форма персистируется, — миграция данных тем же коммитом. Без новой
   версии `--write` поверх ломающих изменений отказывает. Аддитивное —
   `--write` без аргумента, версия наследуется.

## Как запускать

Гейт целиком — команда в `CLAUDE.md` §10 (зеркалит `.github/workflows/ci.yml`).
Отдельно: `python tools/truth.py` (классификация, глоссарий, статичность
импортов), `python tools/schema_lock.py` (форма схемы). Мутационный стенд —
`pytest -m heavy`: дефект в каждую проверку, набор обязан покраснеть; список
охраняемых инструментов выводится из `tools/*.py`. Хук сессии
(`.claude/settings.json`, вне git) уже стоит: `tools/truth.py --hook`.
